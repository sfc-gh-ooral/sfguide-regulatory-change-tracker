Financial Services · Compliance

Turn every new rule into owned, dated work before it takes effect

Regulators publish rules, guidance and consultations every week. Someone has to read each one, decide whether it applies, find the obligations, check them against the firm's policies and controls, and chase the gaps before the effective date. This example does the reading with Snowflake Cortex AI for a fictional bank, and leaves every decision to an analyst, with a reason on record.

Who it is for

Regulatory change analysts

An inbox of new publications with an AI applicability assessment and plain-language summary, and a one-click decision with a reason for the audit trail.

Policy and control owners

Each obligation next to the policy sentence and control that best match it, with similarity scores and a coverage verdict that quotes the decisive wording.

Compliance leaders

A gap tracker with owners, due dates set from the effective date, status and evidence links, and a rulebook you can question in plain language.

How it works

Each capability below ran in live mode on a Snowflake account in AWS US East 1 in November 2026.

StepSnowflake capabilityWhat it does here
IntakeStage with directory table, stream, taskNew notice PDFs on the stage are queued by a stream; a task runs the pipeline procedure when the stream has data.
ReadAI_PARSE_DOCUMENT (OCR mode)Full text of each notice, for search and the AI assessment. Runs in the pipeline, and again on demand from Extract again.
ExtractAI_EXTRACTNotice number, regulator, type, dates and the numbered requirements as a table, one obligation per row.
AssessAI_COMPLETE with structured outputApplies or not, why, products affected and a two-sentence summary, against a firm profile.
MapAI_EMBED and VECTOR_COSINE_SIMILARITYMatches each obligation to the closest policy sentences and controls. Runs in the pipeline, and again on demand from Re-map this obligation.
CheckAI_COMPLETE with structured outputCoverage verdict for the two closest policies and controls, and a conflict check when two policies both match closely.
TrackTables, app write-backGaps with owner, due date, status and evidence; analyst decisions and gap updates are inserted from the app.
AskCortex Search, Cortex AgentsA search service over notice chunks, policies and controls, used by an agent that cites its sources.

Get started

No-account mode

Open the hosted example, or run it locally with Node.js 20.19 or later:

git clone https://github.com/sfc-gh-ooral/sfguide-regulatory-change-tracker.git
cd sfguide-regulatory-change-tracker
npm install && npm run dev

AI answers in this mode are captured from the live app and labeled Sample AI response.

Live mode

  1. Run sql/setup.sql in a Snowsight worksheet as ACCOUNTADMIN.
  2. Register a key pair on your user and copy .env.example to .env.local.
  3. Run npm run dev and switch the header to Live.
  4. Run sql/cleanup.sql when you are done.

Cortex AI functions, Cortex Search and Cortex Agents must be available in your region or through cross-region inference. The README lists every object created, the cost, and the full steps.

Known limits

  • Mapping and coverage verdicts are AI suggestions. On this synthetic set they found the four planted gaps and no others in our runs, but wording can change between runs, so an analyst must review every verdict.
  • Overriding an AI dismissal records the decision but does not re-run coverage checks for that notice's obligations.
  • Each obligation is checked against its two closest policies and two closest controls only.
  • The policy library is a table of short synthetic policies; real libraries need chunking and a review of low-similarity matches.
  • Evidence links are example URLs; the app stores the link and does not fetch it.
